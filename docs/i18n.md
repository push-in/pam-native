# Internationalization

`Pam\Native\I18n\I18n` is a small message catalog in the style of i18next, without dependencies.

## Catalogs

- Register one catalog per locale. Use the language subtag as the locale (`pt`, `en`, `es`, `fr`).
- A catalog maps namespaces to flat `key => text` maps.
- A catalog can be given as a loader closure. Then only the active locale and the source locale are ever loaded.

```php
use Pam\Native\I18n\I18n;

I18n::source('pt');                                   // source of truth and fallback
I18n::catalog('pt', static fn () => require __DIR__.'/Locales/pt.php');
I18n::catalog('en', static fn () => require __DIR__.'/Locales/en.php');
I18n::use($preference ?? $deviceInfo->locale);        // resolved by language subtag
```

`I18n::resolve(...$tags)` returns the first registered language among the tags. `pt_BR`, `es-419` and `fr-CA` all resolve. When nothing matches, it returns the source locale.

The system language is `DeviceInfo::$locale`, a BCP 47 tag:

- Android: `Locale.getDefault()`.
- iOS: the first preferred language.

Apps keep their own override, e.g. a language row in the settings, and choose the locale once per run. A language change should restart the UI.

## Translating

```php
I18n::t('common.action.cancel');                      // "Cancelar"
I18n::t('chat.greeting', ['name' => 'Ana']);          // "{name}" interpolated
I18n::t('feed.likes', ['count' => 1234]);             // "1.234 curtidas"
I18n::list('common.date.monthsShort');                // "jan|fev|…" as a list
```

- **Plurals:** a numeric `count` looks up `key_zero` first (only when the count is 0 and the key exists), then `key_one` or `key_other`.
- **Plural rule:** exactly 1 is `one`. French uses `n < 2`. Use `I18n::pluralRule()` to register other rules.
- **Numbers:** they are grouped for the locale (pt `1.234`, en `1,234`, es `1234` / `12.345`, fr `1 234`).
- **Missing keys:** a key missing in the active locale falls back to the source locale. A key missing in both returns the key itself.

## Templates

`t()` is a template built-in:

```html
<Text>{{ t('common.action.cancel') }}</Text>
<Pressable :accessibilityLabel="t('feed.likesA11y', ['count' => $likes])" />
```

A component method named `t()` takes precedence over the built-in.
